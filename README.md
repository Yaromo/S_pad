# S_pad

Бесплатный аналог Soundpad для linux написанный на python одним любителем в программировании для личного пользования.

> Предупреждение: Разработчик не проверял все возможные конфигурации Linux из-за чего на некоторых системах возможны ошибки.

Основой данной программы является современный мультимедийный сервер и фреймворк для Linux - Pipewire (Если он у вас не установлен, то S_pad работать не будет). 

## Архитектура программы

Для работы программы создается 3 виртуальных устройства соединяемых между друг другом:

  1. My_Virtual_Microphone - Виртуальный микрофон, в который будет выводится звук выбранного вами микрофона и звуки которые вы проигрываете. Его вы подключаете нужной вам программе, для проигрывания звуков.
  2. Mixer_Audio_Sender - Виртуальное аудиоустройтсво, в котором смешивается звук микрофона и проигрывающихся звуков. Отсюда звук выводится на My_Virtual_Microphone.
  3. Music_Sender - Виртуальное аудиоустройтсво, в котором смешивается звук микрофона и проигрывающихся звуков. Отсюда звук выводится на Mixer_Audio_Sender.

> Важно: Не забудьте отключить в вашей программе (в которую вы выводите звук) шумоподавление. (Например в дискорде)

# Быстрый старт

Команда для автоматической установки и старта программы:
```bash
bash <(curl -s https://raw.githubusercontent.com/Yaromo/S_pad/main/setup.sh)
```
Чтобы запустить программу снова используйте файл - start.sh

# Интерфейс

(Без картинок, сверху вниз)

1. Меню: Microphone - выбор микрофона, который будет выводится. Audio - выбор вывода куда будут ВАМ выводится звук ваших аудио файлов. Update - Обновить списки аудио устройств в первых друх вкладках
2. Кнопки управления: change mode - Меняет режим воспроизведения звука: Единичный - один звук проигрывается в одно время, Миксированый - объединяет все проигрывающиеся звуки в один поток. stop/start - пауза и пуск. clear - очистка звукового потока
3. (Слева) Список директорий директории sounds. Нажатие на название поддиректорий меняет таблицу звуков, на таблицу звуков нажатой директории (справа).
4. Таблица звуков: первый столбик кнопка проигрывания, 2 - название файла, 3 - горячая клавиша, 4 - громкость (десятичные дроби писать через точку), 5 - время воспроизведения

> Если в поддиректории есть директория, то она отображается как звук в таблице звуков. Если в ней больше 1 звука то для проигрывания выбирается случайный

# ВАЖНО

Директория для звуков создастся автоматический при первом запуске, не делаете её сами.
